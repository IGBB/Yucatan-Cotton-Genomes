Annotated four wild cotton genomes

*** [[./0-ref/readme.org][References]]

#+header: :dir (symbol-value 'ssh-deploy-root-remote)
#+header: :var ROOT=(file-local-name ssh-deploy-root-remote)
#+header: :var genomes=./0-ref/readme.org:genomes[,0]
#+begin_src shell :colnames '("Genome" "Seqs" "Size")
for name in "${genomes[@]}"; do
    awk '{sum += $2 } END {print name, NR, sum}' \
        name=$name OFS="\t" \
        $ROOT/0-ref/$name.fa.gz.fai
done
#+end_src

*** [[./1-orient/readme.org][Orient and Rename]]
Using [[https://jcottonres.biomedcentral.com/articles/10.1186/s42397-018-0002-1][Wang, Wendel, and Hua 2018]] as refrence for names; specifically [[https://jcottonres.biomedcentral.com/articles/10.1186/s42397-018-0002-1/tables/2][table 2]].

Using /Gossypium longicalyx/ from [[https://academic.oup.com/g3journal/article/10/5/1457/6026205][Grover et al. 2020]] (F1.NSF) as the orientation reference.

#+header: :dir (symbol-value 'ssh-deploy-root-remote)
#+header: :var ROOT=(file-local-name ssh-deploy-root-remote)
#+header: :var genomes=./0-ref/readme.org:genomes[,0]
#+begin_src shell :colnames '("Genome" "Seqs" "Size")

    awk '{sum += $3 } END {print name, NR, sum}' \
    name=$name OFS="\t" \
    $ROOT/1-orient/3-curate-agp/$name.agp
done
